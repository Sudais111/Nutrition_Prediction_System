About This System

This system explores nutrition-related indicators using available survey data from Pakistan and predicts unmeasured combinations with a Decision Tree Regressor.


Dataset: Nutrition Survey Dataset (NNS 2018 & MICS 2018)


Machine Learning: Decision Tree Regressor


Framework: Python Flask


Data Transparency: Results clearly distinguish between measured survey records and modelled ML estimates.

Nutrition Data Overview

Survey Comparability Note: Overview averages combine available NNS 2018 (Islamabad, Pakistan) and MICS 2018 (Punjab, Rawalpindi) records. Because NNS and MICS differ in survey design and measurement, cross-survey values should not be compared directly without caveat.
